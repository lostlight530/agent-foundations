# Code of Conduct


## Scope

This code applies to repository Issues, pull requests, reviews, Discussions, and other public collaboration around this project.

## Expected conduct

Participants should communicate professionally and respectfully, focus criticism on claims and artifacts rather than individuals, disclose uncertainty, protect private information, and respect attribution and third-party rights. Harassment, discrimination, threats, doxxing, impersonation, fabricated evidence, deliberate deception, and repeated disruption are unacceptable.

### 声明与证据纪律 / Claim and evidence discipline

中文：对 Agent 能力、科研出处、架构建议与模型输出的争议应以可核验来源、明确假设和反例讨论，避免将理论图谱、合并的 PR 或阶段展示称为已验证自治能力

English: Disputes about agent capabilities, research sources, architecture proposals and model outputs should rely on verifiable sources, explicit assumptions and counterexamples. A theory graph, merged PR or stage display does not establish verified autonomous capability

## Evidence-aware collaboration

Technical and theoretical disagreement is welcome. Keep repository implementation evidence, validation evidence, external evidence, proposals, hypotheses, and unknown state distinguishable. Do not promote unsupported material into verified capability or silently rewrite historical evidence to match later knowledge.

## Sensitive information

Do not publish credentials, private communications, personal data, or unpublished exploit details. Follow `SECURITY.md` for security-sensitive reports. Conduct concerns containing private information should use an available private contact route rather than a public Issue.

## Moderation

The repository maintainer may edit, hide, remove, lock, or reject contributions that violate these standards or materially undermine repository integrity. Repeated or serious violations may result in participation restrictions.

The repository owner retains final moderation and merge authority.
