## Source-registry architecture

Source IDs are identities, not a count maintained by automation.

Current validator logic requires:

- one contiguous source-ID range
- a canonical Identifier or URL per source
- canonical identity uniqueness
- arXiv versions/revisits collapsed to the base paper identity for duplication checks

A legitimate new source can extend the registry without editing a hard-coded source count in validator logic.

## Research lifecycle SOP

### Daily research

A Daily Research Chunk is a candidate evidence input.

It does not automatically become:

- a new canonical source
- a verified theorem
- a current domain Claim
- a repository implementation
- an experimentally reproduced result

Canonical review may register, reuse, correct, narrow, contest, or leave the material historical-only.

### Weekly synthesis

Weekly synthesis may identify patterns across Daily research, but repeated citation of the same source is inheritance, not independent corroboration.
