# agent-foundations

> The four repositories are what the system does.
> This repository is why it works.

## What This Contains

Academic research that forms the theoretical skeleton 
of a deterministic agent architecture.

| Research Direction | Agent Component | Role |
|-------------------|----------------|------|
| SimCLR + Unsupervised Learning | Memory System | Representation learning, feature extraction, anomaly detection |
| Reinforcement Learning (NLP) | Tool System | Policy optimization, value alignment — studied, then reversed |
| Federated Learning + Spatiotemporal | Collaboration System | Distributed convergence, privacy-preserving aggregation |

## Core Finding

Six research directions in half a year were not random jumps.
They were a systematic survey of the Agent capability matrix —
learning every component, then building from scratch what others approximate with scale.

Five directions learned existing theory.
One direction created new theory: gradient entropy.

That one is elsewhere.

## Principle

We do not implement. We constrain.
We do not scale. We prove.
We do not optimize. We guarantee convergence.
